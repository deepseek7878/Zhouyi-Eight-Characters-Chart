# Bazi Calculator — 八字排盤與周易命理系統原始碼

[English](README.en.md) | [繁體中文](README.zh-TW.md) | [GitHub Pages](https://deepseek7878.github.io/bazi-calculator/)

專案定位为“命理排盘工具 + 傳統文化数字化系統 + 商業应用基础框架”，可用於學習研究、产品原型、SaaS 命理平台、微信/小程序/網頁排盘工具、知识付费系統和咨询服务後台。

> 說明：本專案内容適合傳統文化研究、排盘工具开发和娱乐参考，不应取代法律、医疗、财务、心理咨询等專業建议。
